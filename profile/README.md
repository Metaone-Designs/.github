### The Decentraland scenes

The scenes from the Creators Academy workshops are free to use, and each one builds today. They are listed, with what each one shows, at **[github.com/j-stickel/decentraland-scenes](https://github.com/j-stickel/decentraland-scenes)**.

The `@m1d/dcl-components` library is no longer published. For a starter scene with visitor analytics, use **[thestatic-dcl-free](https://github.com/thestatic-tv/thestatic-dcl-free)** from [thestatic.tv](https://thestatic.tv).
